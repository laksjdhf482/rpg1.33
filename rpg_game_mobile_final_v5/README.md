# 거지 탈출 RPG

Streamlit + HTML/CSS/JavaScript 기반 모바일 9:16 RPG 클릭 게임입니다.

## 스테이지
1. STAGE 1. 거지 — 1,000,000원
2. STAGE 2. 길거리 — 5,000,000원
3. STAGE 3. 서울역 — 50,000,000원
4. STAGE 4. 농사 — 250,000,000원
5. STAGE 5. 아파트 — 1,250,000,000원

각 스테이지의 배경 이미지 안에 캐릭터가 함께 포함되어 있어 별도의 투명 캐릭터 PNG를 화면에 겹치지 않습니다.

## 실행
```bash
pip install -r requirements.txt
streamlit run main.py
```

게임 화면은 9:16 고정 비율이며 스크롤 없이 사용할 수 있습니다.
